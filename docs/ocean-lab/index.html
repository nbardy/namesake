The mathematical choices

Exact repetition and globally unique tiles are different goals. A finite supertile can contain many distinct cells, then repeats them. An irrational phase sequence can keep assigning new interiors forever, while the same hexagonal geometry continues to fit. Sixfold rotations form the discrete group C₆; the continuous Lie group U(1) acts on wave phase.

Shared coordinates
x = B(q,r),    B(q,r) = (√3(q+r/2), 3r/2)
R(q,r) = (−r,q+r)                    [rotation by 60°]
S(u,v) = cos(2πu)+cos(2πv)+cos(2π(u+v))
c = B(m,n)                          [nearest hex center]
ξ = x−c;  a = √3/2                  [cell inradius]
nⱼ = (cos(jπ/3), sin(jπ/3)), j=0…5  [outward face normals]

Hexagon circumradius is one world unit. These formulas describe height fields, not signed-distance fields. Matching height and its first derivatives gives matching surface normals.
